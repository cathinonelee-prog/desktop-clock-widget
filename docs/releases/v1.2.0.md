## 本次更新

- **日历卡片**：在时钟上单击 / 双击 / 悬浮即可弹出日历，用来确认日期和接下来的安排。
  - 激活方式可设：不自动弹出、单击、双击、悬浮（悬浮可设延时，避免鼠标路过就弹）。
  - 隐藏方式可选：鼠标移开自动隐藏（默认延时 0.8 秒，可调，留出移到卡片上的时间），或手动关闭（点卡片右上角 × 或再次点击时钟）。
  - 显示范围：单月 / 双月并排；每周从周一或周日开始；可显示相邻月份补白、周末高亮、农历、节气、
    法定节假日与调休（休 / 班）。
  - 点击穿透模式下点击事件不会传到时钟，此时单击 / 双击无效，可改用悬浮触发。
- **快捷键冲突提示修正**：之前任何设置改动都会弹出一次「快捷键被占用」提示；现在只在快捷键配置变化时重新注册，
  冲突改为「窗口层级」页内联提示（红框 + 一行说明），不再打扰其他设置。

## 下载与安装

- 下载 `DesktopClock-win32-x64.zip`，解压到任意目录，双击 `DesktopClock.exe` 即可，无需安装。
- 程序未做代码签名，首次运行若被 Windows SmartScreen 拦截，点「更多信息 → 仍要运行」即可。

## 升级说明

- 已装旧版本：打开 设置 → 关于 → 版本更新，点「检查更新」即可自动升级。
- 升级只替换程序目录，设置、时钟实例与窗口位置保存在 `%APPDATA%\desktop-clock-widget\`，不会丢失。
