## 本次更新

### 新增：日历卡片

在时钟卡片上单击 / 双击 / 悬浮即可弹出日历，用来快速确认日期和接下来的安排。

- **激活方式**：不自动弹出 / 单击 / 双击 / 悬浮，悬浮可设触发延时（0–3000ms，避免鼠标路过就弹）。
  选择「双击」时，设置改从右键菜单或托盘打开。
- **隐藏方式**：鼠标移开自动隐藏（默认延时 0.8 秒，可调，留出移动到卡片上的时间）或手动关闭（点卡片 × / 再次点击时钟）。
- **显示范围**：单月或双月并排；每周从周一或周日开始；可显示相邻月份补白、周末高亮、农历、节气、
  法定节假日与调休（休 / 班）。卡片宽度固定，切换月份不会跳动。
- 弹出带淡入淡出；卡片按屏幕空间自动选择出现在时钟下方 / 上方 / 左右侧。
- 点击穿透模式下点击不会传到时钟，此时可改用悬浮触发（悬浮判定由主进程轮询光标完成，穿透下同样可用）。
- 右键菜单新增「显示日历卡片」，关掉自动弹出后也能手动调出。

### 新增：更新提示

- 检查到新版本时，除了「设置 → 关于」里的更新卡片，还会弹一次系统通知，并在托盘菜单顶部显示
  「发现新版本 vX.Y.Z，点击更新」；每个版本只提示一次。
- 启动 8 秒后自动检查一次，之后每 6 小时检查一次（可在设置里关闭自动检查）。

### 修复

- **快捷键冲突提示**：之前任何设置改动都会弹出一次「快捷键被占用」提示；现在只在快捷键配置变化时重新注册，
  冲突改为「窗口层级」页内联提示（红框 + 一行说明）。
- **日历闪一下**：日历改为常驻透明窗口，显示 / 隐藏只切换 CSS 透明度，不再反复 show/hide。
- **日历宽度跳动**：网格固定列宽、长节日名省略号截断，切换月份卡片尺寸不再变化。
- **节假日标记不显示**：修复节假日数据缓存 Promise 导致的查询失败，休 / 班标记与「距 XX 假期」恢复。
- **日历无法操作**：悬浮命中区按可见卡片计算（不含四周透明留白），移开隐藏留出足够时间，工具栏按钮加大点击区域。

## 下载与安装

- 下载 `DesktopClock-win32-x64.zip`，解压到任意目录，双击 `DesktopClock.exe` 即可，无需安装。
- 程序未做代码签名，首次运行若被 SmartScreen 拦截，点「更多信息 → 仍要运行」。

## 升级说明

- **已装旧版本**：不用重新下载。启动后会自动检查，发现新版本时右键托盘图标点「发现新版本…」，或打开
  **设置 → 关于 → 版本更新** 点「检查更新」，下载完成后点「重启并安装」即可。
- 升级只替换程序目录，设置、时钟实例与窗口位置保存在 `%APPDATA%\desktop-clock-widget\`，不会被覆盖；
  替换失败会自动回滚到旧版本。
- 程序目录需要可写（便携版解压目录即可）；放在 `Program Files` 下需要管理员权限。
