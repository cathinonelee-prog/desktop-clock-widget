## 本次更新

### 修复：需要代理的网络里无法检查更新

- 之前「检查更新」用的是 Node 自带的网络请求，它**不读取 Windows 系统代理**，所以在需要代理才能访问 GitHub 的网络里
  会直接报 `检查失败：fetch failed`，下载也会卡在 0%。
- 现在改用 Electron 的网络栈（Chromium），会自动使用**系统代理**和系统证书，代理环境下可以正常检查与下载。

### 优化：网络错误提示

- 失败原因会说明具体是哪一类问题：域名解析失败、连接超时（可能缺代理）、证书校验不通过（可能被公司网络拦截）。

## 下载与安装

- 下载 `DesktopClock-win32-x64.zip`，解压到任意目录，双击 `DesktopClock.exe`，无需安装。
- 未做代码签名，首次运行若被 SmartScreen 拦截，点「更多信息 → 仍要运行」。

## 升级说明

- **v1.2.0 用户**：设置 → 关于 → 版本更新，点「检查更新 → 下载 → 重启并安装」即可。
- **v1.1.0 及更早、且当前报 `fetch failed` 的用户**：旧版本的更新器不读系统代理，需要**手动下载一次**这个 zip，
  解压覆盖程序目录（配置文件在 `%APPDATA%\desktop-clock-widget\`，不会被影响），之后再更新就会自动走代理。
