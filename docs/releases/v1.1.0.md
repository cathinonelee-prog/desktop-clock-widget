## 本次更新

- **自动更新**：设置 → 关于里可以直接检查新版本、查看更新说明与下载进度，一键重启完成升级。
  升级只替换程序目录，设置、时钟实例与窗口位置都保存在 `%APPDATA%`，不会被覆盖；替换失败会自动回滚到旧版本。
- **快捷键录制**：全局快捷键改成「点击方框后直接按组合键」录入，按 Esc 取消、Backspace 或右侧 × 清除（留空即停用）。
  组合需要包含 Ctrl / Alt / Shift 之一；被系统里其他程序占用的快捷键会标红提示。
- **低内存模式**：设置 → 窗口层级可开启，关闭 GPU 加速，实测常驻内存从约 220 MB 降到约 147 MB（重启生效）。
- **时区选择修复**：修复时区下拉框无法滚动、页面滚动后弹层仍悬浮不消失的问题；新列表支持滚轮 / 方向键浏览、
  按城市或时区名搜索，并显示每个时区的 UTC 偏移。
- **体积精简**：裁掉用不到的语言包与 dxcompiler.dll，压缩包从约 155 MB 降到约 133 MB，解压后约 287 MB。

## 下载与安装

- 下载 `DesktopClock-win32-x64.zip`，解压到任意目录，双击 `DesktopClock.exe` 即可，无需安装。
- 程序未做代码签名，首次运行若被 Windows SmartScreen 拦截，点「更多信息 → 仍要运行」即可。

## 升级说明

- 已经装过旧版本：打开 设置 → 关于 → 版本更新，点「检查更新」即可自动升级，不用重新下载压缩包。
- 手动覆盖升级也不会丢设置：配置与窗口位置在 `%APPDATA%\desktop-clock-widget\`，不在程序目录里。
